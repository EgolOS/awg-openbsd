## R4-01 — host-wide installer lock — PASS

Defect: three shared-path write sites (backup pair `install.sh:455-467`, ifconfig
install `515-519`, kernel install `875-882`) had nothing serialising two runs; the
pledge-evidence run observed `/bsd` at 0 bytes with the backup pair and staging gone.

Fix: `acquire_lock()` takes an exclusive lock for the whole run (build, publish,
rollback) and `verify_bsd_final()` re-checks `/bsd` before exit (non-empty file,
`sha256` + `stat` size match the manifest).
- OpenBSD 8.0 base has no `flock(1)` (`which flock` fails on the VM), so the lock is
  `mkdir /var/db/awg-install/lock.d` + `pid` file (`74b4171`).
- Operator audit note: `rm -rf` + `mkdir` reclaim is a TOCTOU — two runs seeing the
  same dead pid both win. Reclaim now renames atomically
  (`mv lock.d lock.d.stale.$$`; loser gets ENOENT and dies), retries `mkdir` once,
  writes the pid inside the fresh dir before any other step (`c7cfcd8`).
- Operator audit note: `kill -0` reports EPERM for another user's live process as
  "gone". Liveness is `ps -p "$pid"` with `kill -0` only as fallback (`ac8567f`).

VM 2205 evidence (`docs/evidence/2026-11-08/w1-r4-runA-lock.log`):
```
run2 start 2026-11-08T13:56:50Z
==> Lock acquired: /var/db/awg-install/lock.d (pid 86148)
run2 rc=0
run2 bsd sha: e00ed8f6c42cf99f777409defa6f6ff1ecc5ac39afe9e227bc93bd84aa19b0a2
```
Run 2 started while run 1 was in `Building kernel` (grep count 1 in the log at the
time run 2 ran); run 2 completed with rc=0 and `/bsd` hash unchanged
(e00ed8f6… before and after). Lock dir removed at exit.
Unit tests: lock acquire, refusal while held (pid 1, EPERM-safe), dead-pid reclaim,
missing-pid grace, 8-way reclaim race asserts exactly one winner, pre-exit `/bsd`
hash+size check.

## R4-02 — transactional publish — PASS

Defect: `--all` replaced `ifconfig` before the kernel build (mixed pair on build
failure); backup/manifest publication non-atomic; `/obsd` shared the backup inode;
`--rollback` restored only kernel+ifconfig, not the header.

Fix: `--all` = packages → sources → `ifconfig_build` → `install_awgctl` →
`kernel_build` → `publish_pair`. The pair (kernel, ifconfig, header, awgctl) is
published as one transaction after both artifacts are built. Backups are
generation-stamped and immutable (`/bsd.awg-prev.<gen>`,
`/sbin/ifconfig.awg-prev.<gen>`, `/usr/include/net/if_awg.h.awg-prev.<gen>`,
`/usr/local/sbin/awgctl.awg-prev.<gen>`), never reused in place; `/obsd` is
re-linked to the fresh backup; the manifest (schema=2, records both generations) is
written tmp+rename. Any publish failure calls `restore_previous_pair()` and says so.

Defect: `.gitignore:5` (`*.orig`) excluded `src/kern_pledge.c.orig`, so a fresh

`kern/kern_pledge.c` before stripping the tree, and that `--check` returns non-zero
when the baseline is absent.
