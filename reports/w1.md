## 1. The abort — confirmed, with one correction to the diagnosis

`getifaddrs()` does need `route`, and adding it removes the abort for the
no-argument `show` path. `ktrace` on the aborting `SIOCGAWG` shows the promise
the kernel actually charges for that ioctl:

```
ioctl(3,_IOWR('i',224,0x20),0x73adfb444f78)
PLDG  ioctl, "tty", errno 1 Operation not permitted
PSIG  SIGABRT SIG_DFL
```

OpenBSD 8.0 `sys/kern/kern_pledge.c` names neither `SIOCSAWG` (223) nor
`SIOCGAWG` (224) in its ioctl→promise groups, so both fall through to
`pledge_fail(p, EPERM, PLEDGE_TTY)`. Pledging `tty` alone is not enough for a
socket ioctl — the request number must be in the group's case list — so the
kernel group was extended and the kernel rebuilt:

```c
if ((pledge & PLEDGE_INET)) {
        switch (com) {
        case SIOCSAWG:
        case SIOCGAWG:
        case SIOCATMARK:
        case SIOCGIFGROUP:
                if (fp->f_type == DTYPE_SOCKET)
                        return (0);
```

(`kern_pledge.c` also needed `#include <net/if_awg.h>` for the two constants.)

Before / after, same binary path, `awgctl show awg0` on 2205:

```
BEFORE (HEAD):  Abort trap (core dumped)          rc=134
AFTER  (route+tty): awg0: awgport 51990 / awgpubkey pOCS… / awgversion legacy
                    awgjc 4 awgjmin 10 awgjmax 25 / awgs1 26 awgs2 33
                    awgh1 1737146616 … / awgpeer zo06… / tx: 348, rx: 0
                    groups: awg / inet 10.9.9.1 netmask 0xffffffff   rc=0
```

Shipped pledge set: `stdio rpath inet route tty dns proc exec`.

## 2. show vs ifconfig — field by field

Two mismatches found and fixed:

- `awgh1 100` **and** `awgh1 100-200` were both printed (lo, then the range).
  Now one line, range form, as ifconfig prints it.
- The comparison harness used `sed` with `\n` in the replacement, which BSD sed
  emits as a literal `n` (`awgjc 3nawgjmin 10nawgjmax 25`). Replaced with an
  awk pair-splitting normaliser used for both sides.

After the fixes, `awgctl show` matches `ifconfig` on every compared field for
both the legacy interface (case 2) and the 3.1 interface (case 7), and the
legacy output does not invent the 3.1-only keys.

## 3. HAS_VERSION — verified

`apply_config` now sets `AWG_INTERFACE_HAS_VERSION` only when the input names a
version. Proof on a fresh 3.1 interface (`Version = 3.1`), `show` after each
step:

| step | command | version 3.1 | awgs3 22 |
|---|---|---|---|
| up | `awgctl up awg9 --config awg31.conf` | yes | yes |
| set | `awgctl set awg9 ListenPort 51899` | yes | yes |
| add | `awgctl add awg9 peer AgIC… endpoint … allowed-ips … keepalive 10` | yes | yes |
| del | `awgctl del awg9 peer AgIC…` | yes | yes |

Note: `set` takes the wg-quick key names (`ListenPort`), not the ifconfig names
(`awgport`); `set awg9 awgport 51899` exits 2 with `unknown key 'awgport'`.
That is the documented grammar, so the brief's `awgport` spelling is the
ifconfig name for the same field.

## 5. Other fixes in this pass

- `check_trust` walked every ancestor of the config path; `unveil(2)` hides the
  parents of the unveiled directory, so `stat("/etc/amnezia")` returned ENOENT
  and every `up` failed with exit 1. The walk now stops at `CONF_DIR`.
- The `SIOCGAWG` size probe seeded `awgd_size = 0`/`NULL` buffer;
  `awg_ioctl_get` copies the base struct before consulting `awgd_size`, so the
  probe returned EFAULT. Both the `show` probe and the `up` existence probe now
  seed a real base struct (and the I1–I5 receive buffers in `show`).
- The address is set with `inet … alias` tolerating EEXIST, so a second `up`
  is idempotent (previously `ifconfig: SIOCAIFADDR: File exists` → exit 1).
- Lab fixture: HPK was 45 characters (invalid for a 32-byte key) → 44; the
  bad-config fixtures get `chmod 600` (they were mode 644, so the mode check
  fired before the parse check and the exit code was 1, not 2).
- `awgctl.8` documents `AWGCTL_DEBUG` (SIOCGAWG size-probe trace on stderr).
