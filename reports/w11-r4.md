## Environment note (affects every kernel-touching case)

On this VM the AWG ioctls (`SIOCSAWG`/`SIOCGAWG`) abort with SIGABRT whenever
`pledge(2)` is active: a probe that issues the ioctl with no pledge returns
`ok size=296`, and every pledge word set (`inet`, `tty`, `inet tty`, the full
set) aborts; `ktrace` shows the syscall returning `EPERM … PLEDGE_TTY`. The
running kernel's `kern_pledge.c` (Sep 28, stock 8.0) has no `SIOCSAWG`/`SIOCGAWG`
entries, so the ioctl falls through the ioctl table to the `tty` default and
`pledge_fail(EPERM, PLEDGE_TTY)`; the kernel-side copy of the 296-byte
`awg_interface_io` is what aborts. `ifconfig awgN` (which the suite also runs)
succeeds, so the driver itself is fine. This is a kernel-side artefact of the
2206 build, not of the tool: the same source built against the repo header
(`-I../../src`) and against `<sys>` behaves identically. It is
recorded here so the PASS/FAIL counts below are read correctly — the
`up`-dependent cases fail in baseline and fixed alike for this reason.

## R4-06 (HIGH) — stale private key replayed by an unrelated `set` — PASS

Reproduction (pre-fix binary, new test case 12, `w11-r4-oldbinary.log`):
`set awg9 PrivateKey -` (KEY1 from stdin) followed by an unrelated
`set awg9 ListenPort 51991` leaves the *pre-rotation* key in the kernel
(`show` reports the KEY0 pubkey), and a concurrent pair (slow key write, fast
port write) ends with the loser's write reverting the winner's port.
`read_current()` copied the current key into the config and `apply_config()`
wrote any non-NULL key back; the grouped J/S/H write has the same shape.

Fix (`4655d6d`): `apply_config` writes the private key / HPK only when the
caller supplied one — new `c_update_private` / `c_update_hpk` flags set by the
`set` key parser and the config parser, replacing the `c_private != NULL` /
`c_has_hpk` presence tests. The kernel has no generation counter, so the
grouped read-modify-write is guarded by a compare-and-swap: `awg_generation()`
hashes the full `SIOCGAWG` payload (FNV-1a over the size-probed buffer,
ispec pointers wired), `read_current` records the token, and `cmd_set`
re-reads and compares before `SIOCSAWG`, exiting `EX_IOCTL` with
"concurrent update — the interface changed after the read; nothing written"
on a mismatch.

Same command passing (fixed binary, `w11-r4-fixed.log`): rotate to KEY1,
unrelated `set ListenPort 51991` → `show` reports the KEY1 pubkey *and* port
51991; the concurrent pair's loser exits non-zero and the winner's port plus
the rotated key both survive.

Regression test: `awgctl-test.sh` case 12 (rotate + unrelated set + concurrent
pair, asserting the winner's port and the rotated key).

## R4-07 (MEDIUM) — trust traversal checked only directory and file — PASS

Reproduction (pre-fix): a config under a world-writable intermediate
directory (`$CONFDIR/nested/deep.conf`, mode 777) was accepted (baseline
case 3 "nested config" PASS).

Fix: `open_trusted()` walks the path descriptor-relatively — `open(CONF_DIR,
O_DIRECTORY)` then `openat()` per component — verifying each component:
CONF_DIR and every intermediate directory root-owned and not group/other
writable, symlinked components refused (`fstatat(..., AT_SYMLINK_NOFOLLOW)`),
final component a regular root-owned 0600/0400 file. The checks run on the
descriptor that is then read, so a file swapped between check and read cannot
change what is read.

Same command passing: world-writable intermediate directory and symlinked
component both refused (exit 1); the swapped config reads through the opened
descriptor (KEY0 survives the swap).

Regression test: case 13 (world-writable intermediate dir, symlinked
component, file swapped mid-read).

## R4-08 (MEDIUM) — MTU range vs driver, mutation order, read errors — PASS

Reproduction (pre-fix): `MTU = 9001` was accepted by the parser (exit 134
through the ioctl, i.e. applied) while the driver's `SIOCSIFMTU` takes
1..9000 (`src/if_awg.c`), and `cmd_up()` applied the peer list before the
MTU, so a refused MTU left a changed peer set.

Fix: MTU accepted range is 576..9000 (driver `SIOCSIFMTU` 1..9000, wg-quick
floor 576); `cmd_up` orders the mutations cheapest-failure first — MTU, then
addresses, then `apply_config`, then `up`; peer-file read failures check
`ferror()`/`fclose()`.

Same command passing: `MTU = 100` and `MTU = 9001` both refused with exit 2
and the interface keeps its previous peer count and MTU.

Regression test: case 10 (both MTU values, peer count + MTU unchanged).

## R4-09 (MEDIUM) — false success paths — PASS

Reproduction (pre-fix): `show` on an explicitly named missing interface
exited 0 (ENOTTY treated as "no interfaces"), `set` accepted an unmatched
trailing token, and duplicate-address handling matched a stderr substring.

Fix: `show_interface` returns 1 on `ENOTTY` for an explicitly named target
and `cmd_show`/`main` propagate a non-zero exit; `cmd_set` requires exact
`KEY VALUE` pair arity (odd count → `EX_USAGE`); address installation is
verified with `getifaddrs()` on the target interface (`address_present()`,
prefix stripped, `inet_ntop` compare) instead of parsing ifconfig text;
`run_ifconfig` distinguishes a signal death (`killed by SIGx`) from an exit
code.

Same command passing: `show awg2x` exits non-zero, `set … ListenPort 51993
extra` exits 1, the exact-arity form applies the port, and the address reads
back on the target.

Regression test: case 14 (ENOTTY exit, arity, address readback).

## R4-10 (LOW) — secrets in argv and un-wiped buffers — PASS

Reproduction (pre-fix): a literal key argument was accepted silently and the
serialized buffers were freed without wiping.

Fix: `read_secret()` keeps `-` (stdin) as the documented form and warns on
stderr when a literal is used ("visible in the process listing; prefer
'-'"); `cfg_free()`, the `SIOCSAWG` buffer, the `show`/get buffers and the
`read_current` buffer are wiped with `explicit_bzero(3)` before `free()`.
Documented limitation: the allocator's copy and the kernel's `copyin` copy of
the key are not erasable from userland — `explicit_bzero` covers the tool's
own buffers only.

Same command passing: `set awg2 PrivateKey <literal>` applies the key (the
kernel reports the matching pubkey) and prints the stdin hint.

Regression test: case 15 (literal accepted + warns).
