## What changed

**N2 — the pre-check is dropped, last-writer-wins is the contract.**
The kernel has no generation counter, so the R4-06 token was an FNV-1a hash of
the whole `SIOCGAWG` payload. That payload includes the kernel's echo of the
caller's I1–I5 receive pointers (`src/if_awg.c:3676-3684` — different static
arrays per call) and the live peer counters and last-handshake
(`src/if_awg.c:3606-3612`), so an unchanged 3.1 interface hashed differently
from the value the `set` compared against and was rejected as a concurrent
update. `c_gen`/`c_has_gen`, `fnv1a()` and `awg_generation()` are removed
(`sbin/awgctl/awgctl.c`), the `cmd_set` compare is gone, and `awgctl(8)` now
states that the read and the write are two ioctls and the last `SIOCSAWG`
wins per field group. The R4-06 win is kept: the grouped read-back still
preloads Jc/Jmin/Jmax, S1/S2 and H1–H4, so a `set ListenPort` writes flags 4
(PORT only) after a flags-6 read.

**N3 — read-back compares parsed bytes, family and prefix.**
`address_present()` (`awgctl.c:1676`) parses the requested address with
`inet_pton`, takes the prefix with `strtonum`, drops an IPv6 scope, then walks
`getifaddrs(3)` comparing the address bytes (`memcmp`), the family and the
prefix length derived from the netmask (`mask_bits()`). Presentation text is
never compared, so `fd00:0:0:0:0:0:0:1/128`, `FD00::1/128` and
`fd00:000:0:00:0:0:0:1/128` all match the `fd00::1/128` the kernel stores,
and `fd00::1/64` is rejected against a `/128`. `ifa_name` is null-guarded
before `strcmp` (the operator's crash note) in `address_present()` and in the
`show` walk.

**R4-07 — the trust walk starts at the root.**
`open_trusted()` splits the path into components, opens `/`, then each
component with `openat(fd, comp, O_RDONLY|O_CLOEXEC|O_NOFOLLOW|O_DIRECTORY)`
and `fstat`s the descriptor, so `/etc` and `/etc/amnezia` are validated, not
just `CONF_DIR`; `.` and `..` are rejected as component names; the final
`open` uses `O_NOFOLLOW|O_NONBLOCK` and the `fstat` requires a regular file,
so a FIFO is refused without blocking. `main` runs `parse_request()` (which
calls `open_trusted()`) *before* `unveil(2)`, and the verified descriptor is
passed into `cmd_up`/`parse_config` — the file is read through the descriptor
that was checked, not re-opened by name.

**R4-09 — truthful errors.**
`down` requires exactly 1 argument, `del` exactly 3, `show` at most 1; surplus
arguments are a usage error. `read_current()` returns a status and `cmd_set`
reports `set <if>: SIOCGAWG: <strerror(errno)>` (exit 3) instead of seeding
zeros, so ENOTTY on a non-AWG target is visible. `run_ifconfig_eexist()`
captures the child's stderr through a pipe and checks `WIFSIGNALED(status)`
first: a child killed by a signal that printed "File exists" is reported as
"killed by SIGABRT: File exists", not as idempotence.

**R4-10 — one cleanup path.**
`main` registers `atexit(cleanup_active_cfg)` and each subcommand publishes
its `struct cfg` in `g_active_cfg`, so the `err()`/`errx()` paths (which go
through `exit(3)`) wipe the key, HPK and PSK buffers via `free_secret()`
(`explicit_bzero` + `free`). Literal argv secrets stay accepted (with the
existing warning). `awgctl(8)` gained a SECRET LIFETIME section that names
what userland cannot wipe: the kernel's copy inside the interface structure
(lives until the field is replaced or the interface is destroyed), the argv
strings visible to `ps(1)` until the process area is reclaimed, the stdio
buffers used to read the file, and freed allocator chunks.
