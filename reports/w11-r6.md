## 1. N7 — a missing netmask proved the requested prefix — FIXED

Reproduced (reviewer receipt confirmed against the production function;
the host fixture reproduces it too, case F9): `address_present()` set
`found = 1` whenever `ifa_netmask == NULL`, even with an explicit prefix,
and `mask_bits()` counted the leading ones and stopped, so a
non-contiguous mask matched its leading run.

Fix (`sbin/awgctl/awgctl.c`):
- `address_present()`: with `wantbits >= 0` a NULL netmask `continue`s to
  the next entry instead of matching — the mask is the proof of the prefix.
- `mask_bits()`: after the leading run of ones, every remaining bit must be
  zero; a non-contiguous mask returns -1 and matches nothing.
- IPv6 scope: the `%iface` suffix is stripped before the byte comparison
  (the scope is not part of the address bytes) and the behaviour is now
  stated in `sbin/awgctl/awgctl.8` ("Address is verified … scope … stripped
  … ignored").

Regression test: **F9 (netmask proof)** in
`tools/lab/awgctl-fixture-test.sh`, driven by new fixture knobs
`AWGFIX_NOMASK` (NULL netmask) and `AWGFIX_MASK` (raw hex netmask):
missing mask + explicit /128 (not a match, rc 1), prefix-less control
(rc 0), non-contiguous `0x000000ff` vs requested /8 (not a match) with the
contiguous `0xff000000` control (match), malformed prefix `abc` (exit 2),
scope-qualified `fe80::1%ixn/64` (accepted, scope stripped from the state).
Command: `sh tools/lab/awgctl-fixture-test.sh` — **PASS** (F9 all 6 cases).

## 4. N8 — laptop runner safety — FIXED

`tools/lab/awgctl-r5-laptop.sh` rewritten:
- `AWG_LAB_DISPOSABLE=1` gate (refuses without it).
- Pre-existing `/etc/amnezia` is backed up (`cp -a` into the work dir) and
  restored on every exit path (`trap cleanup EXIT`).
- Reserved interface name `awg9` (default), destroyed and recreated at L0 so
  an existing interface is not half-touched; destroyed again on exit.
- Isolated config root: `awgctl`'s `unveil(2)` confines the config to
  `/etc/amnezia/amneziawg`, so that is the replaced root (the backup/restore
  trap protects a real tree); every case uses `--config` against it.
- All work paths from `mktemp -d` (no predictable `/tmp/awg-r5-*`).
- ktrace/kdump fix: the probe prints the decoded `_IOWR('i',224,0x20)` form
  so the SIOCSAWG count is observed (was informational/0 with the 64-bit
  code); the N4 assertions accept the kernel's real refusal texts
  (`SIOCAIFADDR`, `Too many levels of symbolic links`, `Not a directory`,
  `SIOCSAWG|SIOCGAWG`).

Proved on the OpenBSD 8.0 laptop (native `awgctl` built with `cc`):
- Refusal path: `sh awgctl-r5-laptop.sh` (no gate) →
  `set AWG_LAB_DISPOSABLE=1: the run replaces /etc/amnezia`, rc 1;
  `find /etc/amnezia` before/after is **IDENTICAL: nothing deleted**.
- Gated run: `AWG_LAB_DISPOSABLE=1 sh awgctl-r5-laptop.sh` →
  **PASS** `RESULT: all laptop checks passed` rc 0 (L0–L5, ktrace counts
  one SIOCSAWG for the unchanged and the busy set), and the pre-existing
  `/etc/amnezia/amneziawg/awg9.conf` is restored after the run.
